📝 ভর্তি ব্যবস্থাপনা

এই বিভাগটির ডিজাইন প্রস্তুত। ভর্তি আবেদন সংরক্ষণ ও সম্পাদনা চালু করতে Worker API/ডেটাবেস যুক্ত করতে হবে।

▦ উপস্থিতি ব্যবস্থাপনা

উপস্থিতির তালিকা ও রিপোর্টের ইন্টারফেস রাখা হয়েছে। কার্যকর করতে উপস্থিতি API প্রয়োজন।

▥ পরীক্ষার ফলাফল

ফলাফল যোগ, সম্পাদনা ও প্রকাশের জন্য সংশ্লিষ্ট API প্রয়োজন।

📚 শ্রেণি ব্যবস্থাপনা

শ্রেণি যোগ ও সম্পাদনার জন্য শ্রেণি ব্যবস্থাপনার API প্রয়োজন।

৳ বেতন ও ফি

ফি জমা, বকেয়া ও রসিদ ব্যবস্থাপনার জন্য নিরাপদ ব্যাকএন্ড প্রয়োজন।

▤ রিপোর্ট

শিক্ষার্থী, উপস্থিতি, ফলাফল ও ফি রিপোর্ট তৈরি করতে সংশ্লিষ্ট ডেটা API প্রয়োজন।

☁ ব্যাকআপ ও এক্সপোর্ট

ব্যাকআপ চালু করতে ডেটাবেস অনুযায়ী অনুমোদিত export/backup API যুক্ত করতে হবে।

⚙ একাডেমি সেটিংস

একাডেমির নাম, যোগাযোগ, লোগো ও সিস্টেম সেটিংস সংরক্ষণের জন্য settings API প্রয়োজন।
